# 经营性资产管理系统

基于 Vue3 + Element Plus 的国有资产管理系统前端项目。

## 技术栈

- **Vue 3** - 开发框架
- **Vite** - 构建工具
- **Element Plus** - UI组件库
- **Vue Router** - 路由管理
- **Pinia** - 状态管理
- **Axios** - 接口请求

## 功能模块

### 1. 数据驾驶舱
- 资产总数、出租率、年度收益、待处理预警统计
- 资产类型分布图表
- 月度收益趋势图表
- 智能预警列表

### 2. 资产台账管理
- 资产档案列表（支持搜索、筛选、排序）
- 新增/编辑资产
- 资产详情查看（基本信息、资债权证、生命周期）
- 资产导入/导出
- 一物一码管理

### 3. 租赁招租管理
- 租赁管理（在租、到期、退租状态）
- 招租管理（发布招租、查看报名）
- 租控图可视化
- 续租/退租操作

### 4. 合同签约管理
- 合同列表管理
- 新建/编辑合同
- 合同签约流程
- 合同归档/终止
- 合同模板管理
- 审批流程追踪

### 5. 财务收费管理
- 收费台账（应收、已收、逾期）
- 押金管理（缴纳、退还）
- 电子发票管理
- 收费登记
- 催缴通知

### 6. 巡检维修管理
- 资产巡查（创建、上报、完成）
- 资产报修（报修、派单、完成）
- 工单跟踪
- 问题上报

### 7. 数据报表
- 资产统计（类型分布、数量统计）
- 租赁统计（出租率、到期提醒）
- 台账报表（分类统计）
- 缴费统计（收缴率、趋势）

### 8. 资产地图
- GIS地图展示（模拟）
- 资产标记点
- 区域分布统计
- 资产类型分布
- 资产详情查看

## 项目结构

```
src/
├── api/                    # 接口请求（待扩展）
├── assets/                 # 静态资源
├── components/
│   └── Layout.vue          # 布局组件
├── router/
│   └── index.js            # 路由配置
├── store/
│   └── app.js              # Pinia状态管理
├── utils/
│   └── request.js          # Axios封装
── views/
│   ├── AssetLedger/        # 资产台账管理
│   ├── LeaseManagement/    # 租赁招租管理
│   ├── ContractManagement/ # 合同签约管理
│   ├── FinanceManagement/  # 财务收费管理
│   ├── InspectionMaintenance/ # 巡检维修管理
│   ├── DataReport/         # 数据报表
│   ├── AssetMap/           # 资产地图
│   └── DataCockpit/        # 数据驾驶舱
├── App.vue
└── main.js
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```
